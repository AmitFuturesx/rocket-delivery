# One group per crawler. A crawler obeys only the FIRST group that matches it,
# so there is exactly one "User-agent: *" here and everything it needs is
# inside it. The 404 page is not disallowed on purpose: it is served with a
# 404 status and carries meta noindex, and blocking it in robots would stop
# Google reading that noindex at all.
